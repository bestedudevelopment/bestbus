How the odometer handover works
1
Admin sets the baseline

Save the current real odometer and indicate whether it is after pickup or after drop.

2
Driver enters the next stage

The system should ask for the next expected reading only, instead of four readings per day.

3
Reading carries forward

Each accepted reading becomes the baseline for the next stage. Daily kilometres are calculated from consecutive readings.

Data quality

Start with a verified odometer reading.

Accurate baseline readings help calculate daily kilometres and fuel-interval mileage. If a reading is entered incorrectly, an authorised correction should be recorded rather than silently overwriting history.
